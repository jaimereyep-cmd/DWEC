# Batería 0 · Explícalo con tus palabras

Contesta **sin mirar los apuntes**, con tus palabras y en dos o tres líneas. Un ejemplo de código vale más que una
definición copiada.

1. ¿Qué diferencia hay entre `console.log(x)` y `return x` dentro de una función? ¿Cuándo usas cada uno?

2. Tienes `let total = 0;` antes de un `for`. ¿Para qué sirve? ¿Qué pasaría si lo pusieras **dentro** del `for`?

3. ¿Qué diferencia hay entre `filter`, `find` y `map`? Pon un ejemplo de cada uno con una lista de productos.

4. ¿Qué es `this` dentro de una clase? ¿Por qué `precio` a secas no funciona dentro de un método y `this.precio` sí?

5. ¿Por qué se guarda en `localStorage` con `JSON.stringify` y se lee con `JSON.parse`? ¿Qué pasa si no lo haces?
